# 🛡️ PinTrace — Security Dashboard (Level 01)

A lightweight, web-based security monitoring platform designed to check website health, monitor traffic, detect threats, and manage security events.

This repository marks **Level 01** of the 24-level **PinTrace Roadmap**, focusing purely on semantic HTML structure without CSS or JavaScript.

---

## 🎯 Objective: Level 01 (HTML Skeleton)

The goal of this stage is to build the structural foundation (the "bones") of the PinTrace Security Dashboard using semantic HTML5 elements.

### Core Structure:
- **Branding Header:** App name (`PinTrace`).
- **Navigation:** Links to `Dashboard`, `Websites`, `Security Events`, `Blocked IPs`, and `Settings`.
- **Security Overview:** Key KPI metrics (Protected Websites, Threats Blocked, Uptime).
- **Recent Security Events:** Structured table displaying IP addresses, threat vectors (XSS, SQLi), and actions taken.
